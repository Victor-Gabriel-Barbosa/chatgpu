      Executa o streaming da resposta do assistente via WebLLM e atualiza as mensagens e métricas progressivamente.

      Parameters

      • engine: WebWorkerMLCEngine

        Instância ativa do motor Web Worker MLC.

      • chatHistory: Message[]

        Histórico de mensagens a ser enviado como contexto para o modelo.

      • chatId: string

        Identificador do chat atual para persistência das mensagens.

      • setMessages: Dispatch<SetStateAction<Message[]>>

        Função de atualização do estado local de mensagens.

      • updateChatMessages: (id: string, msgs: Message[]) => void

        Função responsável por atualizar as mensagens na lista de chats e no IndexedDB.

      • OptionalonSpeedUpdate: (speed: number | null) => void

        Callback opcional para notificar a velocidade atual de geração em tokens por segundo.

      Returns Promise<void>

      Remarks

      Adiciona uma mensagem vazia com papel assistant ao histórico, consome o stream retornado pelo motor MLC, calcula métricas de geração (como tokens por segundo e tempo até o primeiro token) e persiste o resultado final no banco de dados local.
